# types

| File                    | Purpose                                                                                 |
| ----------------------- | --------------------------------------------------------------------------------------- |
| `index.ts`              | Shared domain types and the API envelope                                                |
| `database.generated.ts` | Generated by `pnpm db:types`. Never edited by hand; gitignored from lint and formatting |

## Boundaries

- Generated row types stop at the repository layer
- Domain types may contain decrypted values; view DTOs must not
- A field that exists only for internal logic (dedup keys, hashes, wrapped keys) never
  appears in a view DTO
